## Offre et fonctionnalités

`GET /compte` indique les fonctionnalités disponibles pour la page. Un script peut par exemple vérifier `fonctions.programmation.incluse` avant de définir des dates sur un bloc.

```json
{
  "compte": {
    "pseudo": "camille",
    "adresse": "https://hopla.page/camille",
    "cree": "2026-10-20T09:12:00.000Z",
    "offre": "pro",
    "essai": null,
    "abonnement": { "offre": "pro", "statut": "active", "periode": "mois", "finPeriode": "2026-11-20T09:12:00.000Z" },
    "offreOfferte": null,
    "fonctions": {
      "programmation": { "incluse": true, "offre": "starter" },
      "listeEmail": { "incluse": true, "offre": "pro" },
      "api": { "incluse": true, "offre": "pro" }
    },
    "historiqueStats": 365
  }
}
```

| Champ | Description |
| --- | --- |
| `offre` | Offre effective, période d’essai comprise : `gratuit`, `starter`, `pro` ou `premium` |
| `essai` | La fin de l’essai de Pro, ou `null` |
| `abonnement` | Abonnement payant : offre, statut, mensuel ou annuel, fin de la période en cours |
| `offreOfferte` | Une offre offerte par Hopla, et sa fin (`null` : sans fin) |
| `fonctions` | Chaque fonctionnalité soumise à une offre : incluse ou non, et l’offre requise |
| `historiqueStats` | Profondeur d’historique des statistiques accessible, en jours |

Le changement d’offre, le paiement et la résiliation se font uniquement dans le back office, jamais par l’API.

## Clés d’API

`GET /cles` liste les clés du compte sans exposer leur valeur : nom, premiers caractères, permission d’écriture, date de dernière utilisation. `courante` désigne la clé utilisée pour la requête.

```json
{
  "cles": [
    { "id": "2916f190dae2", "nom": "Claude Code", "debut": "hopla_hT-a", "ecriture": true, "cree": "2026-10-28T10:00:00.000Z", "utilisee": "2026-10-28T21:40:00.000Z", "courante": true }
  ]
}
```

La création et la révocation des clés se font dans Réglages, **API et MCP** : une clé ne peut pas en créer une autre. Voir [Clés d’API](/cles).

## Export des données

`GET /export` renvoie l’ensemble des données du compte en JSON : compte et offre, réglages, blocs, vues et clics (sans adresse IP), inscrits et clés (sans leur valeur). Il correspond au droit d’accès RGPD et contient les mêmes données que « Exporter mes données » dans Réglages, sans les fichiers images (leurs URL sont incluses).

```bash
curl https://app.hopla.page/api/v1/export \
  -H "Authorization: Bearer $HOPLA_CLE" -o mes-donnees-hopla.json
```
