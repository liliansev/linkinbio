## L’offre et ce qu’elle comprend

`GET /compte` dit ce que ta page peut faire aujourd’hui. Utile avant d’envoyer un bloc réservé : un script peut vérifier `fonctions.programmation.incluse` avant de poser des dates.

```json
{
  "compte": {
    "pseudo": "camille",
    "adresse": "https://hopla.page/camille",
    "cree": "2026-10-20T09:12:00.000Z",
    "offre": "pro",
    "essai": null,
    "abonnement": { "offre": "pro", "statut": "active", "periode": "mois", "finPeriode": "2026-11-20T09:12:00.000Z" },
    "offreOfferte": null,
    "fonctions": {
      "programmation": { "incluse": true, "offre": "starter" },
      "listeEmail": { "incluse": true, "offre": "pro" },
      "api": { "incluse": true, "offre": "pro" }
    },
    "historiqueStats": 365
  }
}
```

| Champ | Ce qu’il dit |
| --- | --- |
| `offre` | Ce que la page peut, essai compris : `gratuit`, `starter`, `pro` ou `premium` |
| `essai` | La fin de l’essai de Pro, ou `null` |
| `abonnement` | Ce que tu paies : l’offre, son statut, mois ou année, la fin de la période en cours |
| `offreOfferte` | Une offre offerte par Hopla, et sa fin (`null` : sans fin) |
| `fonctions` | Chaque fonction réservée : incluse ou non, et l’offre qui la donne |
| `historiqueStats` | Les jours de stats que ton offre laisse lire |

Changer d’offre, payer ou résilier se fait dans le back office, jamais par l’API : rien n’est prélevé sans toi.

## Tes clés

`GET /cles` liste les clés du compte, jamais les clés elles-mêmes : leur nom, leurs premiers caractères, si elles modifient, quand elles ont servi pour la dernière fois. `courante` marque celle qui fait l’appel.

```json
{
  "cles": [
    { "id": "2916f190dae2", "nom": "Claude Code", "debut": "hopla_hT-a", "ecriture": true, "cree": "2026-10-28T10:00:00.000Z", "utilisee": "2026-10-28T21:40:00.000Z", "courante": true }
  ]
}
```

Créer et révoquer une clé se font dans Réglages, **API et MCP** : une clé ne peut pas en fabriquer une autre. Voir [Clés d’API](/cles).

## Tes données, en un fichier

`GET /export` rend tout ce que Hopla garde de ton compte, en JSON : ton compte et ton offre, tes réglages, tes blocs, chaque vue et chaque clic (sans adresse IP), tes inscrits et tes clés (sans elles). C’est ton droit d’accès (RGPD), les mêmes données que « Exporter mes données » dans Réglages, sans les images : leurs adresses y sont.

```bash
curl https://app.hopla.page/api/v1/export \
  -H "Authorization: Bearer $HOPLA_CLE" -o mes-donnees-hopla.json
```
