<RoutesDe tag="Email list" />

The `inscription` block (email signup, Pro plan) stores each subscriber in Hopla and forwards it to the integration configured in **Intégrations** (Integrations): Brevo, Mailchimp, Kit, MailerLite, beehiiv, Systeme.io, MailCheap, Loops, or Make, Zapier and n8n via webhook. The API lets you read and manage this list.

<Callout title="Personal data">
  Email addresses are personal data. A key with access to the list can read all of them: only use it with trusted tools, and use a read-only key for dashboards.
</Callout>

## Summary

```bash
curl https://app.hopla.page/api/v1/liste -H "Authorization: Bearer $HOPLA_API_KEY"
```

```json
{
  "liste": {
    "inscrits": 128,
    "semaine": 9,
    "enAttente": 0,
    "branchee": { "outil": "brevo", "liste": "Newsletter", "cle": "xkeysib-…a3f" }
  }
}
```

`inscrits` is the total, `semaine` the subscribers of the last 7 days. `enAttente` counts subscribers not yet synced to the newsletter (provider unavailable, or no integration configured). `branchee` (connected integration) is `null` without an integration; only a masked prefix of the integration credential is returned.

## Subscribers

Newest first, 100 per page (up to 500 with `limite`). Offset pagination: pass the `suivant` (next) value of a response as the `depart` parameter of the next request, until it is `null`.

<Tabs items={['curl', 'JavaScript', 'Python']} groupId="language" persist>

<Tab value="curl">

```bash
curl "https://app.hopla.page/api/v1/inscrits?limite=100&depart=0" \
  -H "Authorization: Bearer $HOPLA_API_KEY"
```

</Tab>

<Tab value="JavaScript">

```js title="all-subscribers.mjs"
const all = [];
let offset = 0;
while (offset !== null) {
  const response = await fetch(`https://app.hopla.page/api/v1/inscrits?limite=500&depart=${offset}`, {
    headers: { Authorization: `Bearer ${process.env.HOPLA_API_KEY}` },
  });
  const page = await response.json();
  all.push(...page.inscrits);
  offset = page.suivant;
}
console.log(all.length, 'subscribers');
```

</Tab>

<Tab value="Python">

```python title="all_subscribers.py"
import os, requests

subscribers, offset = [], 0
while offset is not None:
    page = requests.get(
        "https://app.hopla.page/api/v1/inscrits",
        params={"limite": 500, "depart": offset},
        headers={"Authorization": f"Bearer {os.environ['HOPLA_API_KEY']}"},
    ).json()
    subscribers += page["inscrits"]
    offset = page["suivant"]
print(len(subscribers), "subscribers")
```

| --- | --- |

| `source` | Referrer: `instagram`, `tiktok`, `qr`, `direct`… |
| `envoye` | Already synced to the newsletter |

## CSV export

`?format=csv` returns the full list as a single file, like the admin panel export: `email,prenom,inscrit,source`.

```bash
curl "https://app.hopla.page/api/v1/inscrits?format=csv" \
  -H "Authorization: Bearer $HOPLA_API_KEY" -o subscribers.csv
```

## Delete a subscriber

For an erasure request: `DELETE /inscrits/{id}` permanently deletes the subscriber from Hopla. The copy already synced to the newsletter is not deleted: remove it from that provider as well.

```bash
curl -X DELETE https://app.hopla.page/api/v1/inscrits/92c5ca872beb \
  -H "Authorization: Bearer $HOPLA_API_KEY"
```

## Sync pending subscribers

After configuring an integration or after a provider outage, `POST /inscrits/envoyer` pushes pending subscribers and returns the counts: `envoyes` (sent) and `erreurs` (rejected).

```json title="200 OK"
{ "envoyes": 9, "erreurs": 0 }
```

Without a configured integration, the API returns 409 `rien_de_branche`. Integrations are configured in the admin panel, **Intégrations**: their credentials never go through the API.
