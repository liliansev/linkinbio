---
title: Glossary
description: English equivalents of the French identifiers used by the API and the MCP server.
---

Hopla is built in French, and its API identifiers (paths, fields, enum values, MCP tools) are kept as they are in the product. This page maps them to English.

## Paths

| Path | Resource |
| --- | --- |
| `/page` | Page |
| `/reglages` | Settings |
| `/blocs`, `/blocs/{id}` | Blocks |
| `/blocs/{id}/dupliquer` | Duplicate a block |
| `/ordre` | Block order |
| `/medias` | Images (media) |
| `/stats`, `/stats/semaine`, `/stats/resume` | Analytics, weekly views, summary |
| `/qr` | QR code |
| `/liste` | Email list |
| `/inscrits`, `/inscrits/envoyer` | Subscribers, sync subscribers |
| `/apercu` | URL preview (metadata) |
| `/flux` | Feed |
| `/avis` | Reviews (rating) |
| `/compte` | Account |
| `/cles` | API keys |
| `/export` | Data export |
| `/themes`, `/reseaux`, `/pictos`, `/types` | Themes, social networks, icons, block types |

## Common fields

| Field | English |
| --- | --- |
| `adresse` | URL (public page URL) |
| `pseudo` | Username |
| `offre` | Plan (`gratuit` = free) |
| `essai` | Trial |
| `abonnement` | Subscription |
| `fonctions` | Features |
| `profil` (`nom`, `bio`, `avatar`) | Profile (name, bio, photo) |
| `reseaux` (`reseau`, `url`) | Social links (network, URL) |
| `couleurs` (`fond`, `boutons`, `accent`) | Colors (background, buttons, accent) |
| `bouton` (`style`, `forme`, `ombre`) | Button (style, shape, shadow) |
| `partage` | Share button |
| `vouvoiement` | Formal "vous" form in page copy |
| `redirection` | Redirect |
| `imageFond` | Background image |
| `titre`, `sousTitre` | Title, subtitle |
| `icone` | Icon |
| `public` | Visible |
| `vedette` | Featured |
| `debut`, `fin` | Start, end |
| `compteARebours` | Countdown |
| `prix`, `montants` | Price, amounts |
| `questions` (`question`, `reponse`) | FAQ items (question, answer) |
| `preuve` (`note`, `nombre`) | Social proof (rating, count) |
| `position` | Position |
| `masquer` | Hide |
| `chemin` | Path |
| `jours`, `du`, `au`, `periode` | Days, from, to, period |
| `vues`, `visiteurs`, `clics` | Views, visitors, clicks |
| `serie`, `sources`, `appareils`, `pays`, `precedent`, `avant` | Time series, referrers, devices, countries, previous period, previous value |
| `inscrits`, `prenom`, `inscrit`, `envoye` | Subscribers, first name, signup date, synced |
| `limite`, `depart`, `suivant` | Limit, offset, next offset |
| `enAttente`, `branchee`, `outil` | Pending, connected integration, provider |
| `envoyes`, `erreurs` | Sent, failed |
| `cles` (`nom`, `debut`, `ecriture`, `cree`, `utilisee`, `courante`) | API keys (name, prefix, write access, created, last used, current) |
| `erreur` | Error |
| `supprime` | Deleted (id) |
