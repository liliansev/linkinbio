## Points essentiels

<Cards>
  <Card title="Offre Pro requise" href="/compte">
    L’API et le serveur MCP font partie de l’offre Pro, et des 14 jours d’essai à l’inscription.
  </Card>
  <Card title="Authentification" href="/cles">
    Les clés se créent dans Réglages. Une clé en lecture seule ne modifie aucune donnée.
  </Card>
  <Card title="Limites de débit" href="/limites-et-erreurs">
    120 requêtes par minute et 5 000 par jour pour une clé. Au-delà, l’API répond 429 avec le délai d’attente.
  </Card>
</Cards>
