## Key concepts

<Cards>
  <Card title="Pro plan required" href="/account">
    The API and MCP server are included in the Pro plan and in the 14-day trial.
  </Card>
  <Card title="Authentication" href="/authentication">
    API keys are created in the admin panel. Read-only keys cannot modify any data.
  </Card>
  <Card title="Rate limits" href="/errors">
    120 requests per minute and 5,000 per day per key. Above that, the API returns 429 with a Retry-After header.
  </Card>
</Cards>

## Versions

This documentation covers API v2. API v1 (`/api/v1`), released on October 28, 2026 with French field names, remains supported for existing integrations: see [Migrating from v1](/migrating-from-v1).

Every page of this documentation is available as Markdown: use **Copy Markdown** to pass it to an agent as is.
