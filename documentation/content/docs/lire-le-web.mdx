Lorsqu’une URL est collée dans le back office, Hopla en extrait le titre, l’image et, pour un produit, le prix. Ces trois routes exposent la même extraction, pour remplir un bloc depuis un script ou un agent.

Chaque route attend une URL `https://` dans `url`. La page est récupérée depuis les serveurs de Hopla, sans cookie, et seules les adresses publiques sont acceptées. Limite : 30 requêtes par compte toutes les 10 minutes ; au-delà, 429 `trop_de_lectures`.

## Métadonnées d’un site

```bash
curl -X POST https://app.hopla.page/api/v1/apercu \
  -H "Authorization: Bearer $HOPLA_CLE" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://boutique.exemple.fr/programme", "image": "partage"}'
```

```json
{
  "apercu": {
    "titre": "Programme 8 semaines",
    "description": "Un plan simple pour reprendre le sport.",
    "prix": "49 €",
    "image": "data:image/webp;base64,…"
  }
}
```

| `image` | Résultat |
| --- | --- |
| `true` (par défaut) | L’image de partage du site, ou à défaut son favicon |
| `false` | Le texte seul, plus rapide |
| `"partage"` | L’image de partage, ou rien : la photo d’un produit |
| `"logo"` | Le logo du site, cherché dans ses icônes |
| `"vignette"` | La meilleure vignette pour un bouton de lien |

L’image est renvoyée en data URL : pour l’utiliser dans un bloc, envoyez-la telle quelle à [`POST /medias`](/images). Un site injoignable, ou qui ne répond pas en HTML, renvoie 422 `site_illisible`.

## Flux RSS et chaînes YouTube

```bash
curl -X POST https://app.hopla.page/api/v1/flux \
  -H "Authorization: Bearer $HOPLA_CLE" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://exemple.fr/blog"}'
```

Renvoie les trois derniers articles, du plus récent au plus ancien : `titre`, `url`, `date`, `image`, et `video` pour un épisode. L’URL peut être celle du flux (RSS, Atom) ou d’une page qui le déclare. Avec `{"video": true}` et l’URL d’une chaîne YouTube, renvoie la dernière vidéo longue. Sans flux exploitable : `{"articles": []}`.

## Note d’une page d’avis

```bash
curl -X POST https://app.hopla.page/api/v1/avis \
  -H "Authorization: Bearer $HOPLA_CLE" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://fr.trustpilot.com/review/exemple.fr"}'
```

```json
{ "note": { "note": 4.6, "nombre": 1820, "source": "Trustpilot" } }
```

La note est ramenée sur 5. Elle provient de Trustpilot, ou de toute page qui la déclare dans ses données structurées (`aggregateRating`). Sans note déclarée, ou si la page bloque les robots, la réponse est `{"note": null}`. Les fiches Google ne sont pas prises en charge : saisissez la note manuellement dans le bloc `preuve`.
