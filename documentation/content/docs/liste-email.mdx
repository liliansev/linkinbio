<RoutesDe tag="Liste e-mail" />

Le bloc `inscription` (« Rejoins ma liste », offre Pro) garde chaque inscrit chez Hopla, et l’envoie aussi à la newsletter ou à l’automatisation que tu as branchée dans **Intégrations** : Brevo, Mailchimp, Kit, MailerLite, beehiiv, Systeme.io, MailCheap, Loops, ou Make, Zapier et n8n par un webhook. L’API lit cette liste et agit dessus.

<Callout title="Des données personnelles">
  Ces adresses sont celles de tes visiteurs. Une clé qui lit ta liste les lit toutes : réserve-la à un outil de confiance, et préfère la lecture seule pour un tableau de bord.
</Callout>

## Le résumé

```bash
curl https://app.hopla.page/api/v1/liste -H "Authorization: Bearer $HOPLA_CLE"
```

```json
{
  "liste": {
    "inscrits": 128,
    "semaine": 9,
    "enAttente": 0,
    "branchee": { "outil": "brevo", "liste": "Newsletter", "cle": "xkeysib-…a3f" }
  }
}
```

`enAttente` compte les inscrits pas encore partis vers ta newsletter (elle ne répondait pas, ou rien n’était branché). `branchee` vaut `null` sans intégration ; la clé de ta newsletter n’en montre que le début.

## Les inscrits

Du plus récent au plus ancien, 100 par page (500 au plus avec `limite`). Passe le `suivant` d’une page en `depart` de la suivante, jusqu’à ce qu’il vaille `null`.

<Tabs items={['curl', 'JavaScript', 'Python']} groupId="langage" persist>

<Tab value="curl">

```bash
curl "https://app.hopla.page/api/v1/inscrits?limite=100&depart=0" \
  -H "Authorization: Bearer $HOPLA_CLE"
```

</Tab>

<Tab value="JavaScript">

```js title="tous-les-inscrits.mjs"
const tous = [];
let depart = 0;
while (depart !== null) {
  const reponse = await fetch(`https://app.hopla.page/api/v1/inscrits?limite=500&depart=${depart}`, {
    headers: { Authorization: `Bearer ${process.env.HOPLA_CLE}` },
  });
  const page = await reponse.json();
  tous.push(...page.inscrits);
  depart = page.suivant;
}
console.log(tous.length, 'inscrits');
```

</Tab>

<Tab value="Python">

```python title="tous_les_inscrits.py"
import os, requests

tous, depart = [], 0
while depart is not None:
    page = requests.get(
        "https://app.hopla.page/api/v1/inscrits",
        params={"limite": 500, "depart": depart},
        headers={"Authorization": f"Bearer {os.environ['HOPLA_CLE']}"},
    ).json()
    tous += page["inscrits"]
    depart = page["suivant"]
print(len(tous), "inscrits")
```

</Tab>

```json
{
  "inscrits": [
    { "id": "92c5ca872beb", "email": "ana@exemple.fr", "prenom": "Ana", "inscrit": "2026-10-27T18:02:11.000Z", "source": "instagram", "envoye": true }
  ],
  "total": 128,
  "suivant": 100
}
```

| Champ | Ce qu’il dit |
| --- | --- |
| `prenom` | Vide si le bloc ne le demandait pas |
| `source` | D’où venait le visiteur : `instagram`, `tiktok`, `qr`, `direct`… |
| `envoye` | Déjà parti vers ta newsletter |

## Tout en CSV

`?format=csv` rend tout le fichier d’un coup, comme l’export du back office : `email,prenom,inscrit,source`.

```bash
curl "https://app.hopla.page/api/v1/inscrits?format=csv" \
  -H "Authorization: Bearer $HOPLA_CLE" -o inscrits.csv
```

## Supprimer un inscrit

Pour une demande d’effacement : `DELETE /inscrits/{id}` le retire de ta liste chez Hopla, pour de bon. La copie partie vers ta newsletter y reste : efface-la là-bas aussi.

```bash
curl -X DELETE https://app.hopla.page/api/v1/inscrits/92c5ca872beb \
  -H "Authorization: Bearer $HOPLA_CLE"
```

## Envoyer ceux qui attendent

Tu viens de brancher ta newsletter, ou elle était en panne ? `POST /inscrits/envoyer` pousse les inscrits en attente vers elle et dit combien sont partis.

```json title="200 OK"
{ "envoyes": 9, "erreurs": 0 }
```

Sans rien de branché, l’API répond 409 `rien_de_branche`. Brancher une newsletter se fait dans le back office, **Intégrations** : sa clé ne passe jamais par l’API.
