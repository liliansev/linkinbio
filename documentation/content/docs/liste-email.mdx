<RoutesDe tag="Liste e-mail" />

Le bloc `inscription` (« Rejoins ma liste », offre Pro) enregistre chaque inscrit chez Hopla et le transmet à l’intégration configurée dans **Intégrations** : Brevo, Mailchimp, Kit, MailerLite, beehiiv, Systeme.io, MailCheap, Loops, ou Make, Zapier et n8n par webhook. L’API permet de consulter et de gérer cette liste.

<Callout title="Données personnelles">
  Ces adresses sont des données personnelles. Une clé ayant accès à la liste peut toutes les lire : réservez-la à des outils de confiance, et utilisez une clé en lecture seule pour un tableau de bord.
</Callout>

## Résumé

```bash
curl https://app.hopla.page/api/v1/liste -H "Authorization: Bearer $HOPLA_CLE"
```

```json
{
  "liste": {
    "inscrits": 128,
    "semaine": 9,
    "enAttente": 0,
    "branchee": { "outil": "brevo", "liste": "Newsletter", "cle": "xkeysib-…a3f" }
  }
}
```

`enAttente` compte les inscrits pas encore transmis à la newsletter (service indisponible, ou aucune intégration configurée). `branchee` vaut `null` sans intégration ; seul le début de la clé de l’intégration est affiché.

## Inscrits

Du plus récent au plus ancien, 100 par page (500 maximum avec `limite`). Pagination par curseur : passez la valeur `suivant` d’une réponse en paramètre `depart` de la requête suivante, jusqu’à ce qu’elle vaille `null`.

<Tabs items={['curl', 'JavaScript', 'Python']} groupId="langage" persist>

<Tab value="curl">

```bash
curl "https://app.hopla.page/api/v1/inscrits?limite=100&depart=0" \
  -H "Authorization: Bearer $HOPLA_CLE"
```

</Tab>

<Tab value="JavaScript">

```js title="tous-les-inscrits.mjs"
const tous = [];
let depart = 0;
while (depart !== null) {
  const reponse = await fetch(`https://app.hopla.page/api/v1/inscrits?limite=500&depart=${depart}`, {
    headers: { Authorization: `Bearer ${process.env.HOPLA_CLE}` },
  });
  const page = await reponse.json();
  tous.push(...page.inscrits);
  depart = page.suivant;
}
console.log(tous.length, 'inscrits');
```

</Tab>

<Tab value="Python">

```python title="tous_les_inscrits.py"
import os, requests

tous, depart = [], 0
while depart is not None:
    page = requests.get(
        "https://app.hopla.page/api/v1/inscrits",
        params={"limite": 500, "depart": depart},
        headers={"Authorization": f"Bearer {os.environ['HOPLA_CLE']}"},
    ).json()
    tous += page["inscrits"]
    depart = page["suivant"]
print(len(tous), "inscrits")
```

| Champ | Description |
| --- | --- |
| `prenom` | Vide si le bloc ne le demande pas |
| `source` | Provenance du visiteur : `instagram`, `tiktok`, `qr`, `direct`… |
| `envoye` | Déjà transmis à la newsletter |

## Export CSV

`?format=csv` renvoie la liste complète en un seul fichier, comme l’export du back office : `email,prenom,inscrit,source`.

```bash
curl "https://app.hopla.page/api/v1/inscrits?format=csv" \
  -H "Authorization: Bearer $HOPLA_CLE" -o inscrits.csv
```

## Supprimer un inscrit

Pour une demande d’effacement : `DELETE /inscrits/{id}` supprime définitivement l’inscrit chez Hopla. La copie transmise à la newsletter n’est pas supprimée : effacez-la également dans ce service.

```bash
curl -X DELETE https://app.hopla.page/api/v1/inscrits/92c5ca872beb \
  -H "Authorization: Bearer $HOPLA_CLE"
```

## Synchroniser les inscrits en attente

Après la configuration d’une intégration ou une indisponibilité du service, `POST /inscrits/envoyer` transmet les inscrits en attente et renvoie le nombre d’envois.

```json title="200 OK"
{ "envoyes": 9, "erreurs": 0 }
```

Sans intégration configurée, l’API répond 409 `rien_de_branche`. La configuration d’une intégration se fait dans le back office, **Intégrations** : sa clé ne transite jamais par l’API.
