title: Serveur MCP
description: Gérer une page Hopla depuis Claude, Cursor ou tout client MCP, en langage naturel.
---

Le serveur MCP de Hopla expose à un agent IA les mêmes opérations que l’API : lecture de la page, ajout de liens, modification du thème, consultation des statistiques. L’agent sélectionne les outils à appeler à partir d’instructions en langage naturel.

- **Adresse** : `https://app.hopla.page/mcp`
- **Transport** : HTTP « streamable », réponses JSON, sans session
- **Clé** : `Authorization: Bearer hopla_…`, comme pour l’API

## Installation

Créez d’abord une [clé d’API](/cles), puis configurez le serveur dans votre client.

<Tabs items={['Claude Code', 'Cursor', 'VS Code', 'Windsurf', 'Claude Desktop']} groupId="client" persist>

<Tab value="Claude Code">

```bash title="Terminal"
claude mcp add --transport http hopla https://app.hopla.page/mcp \
  --header "Authorization: Bearer hopla_…"
```

Ajoutez `--scope user` pour l’activer dans tous vos projets. Vérifiez ensuite la connexion avec `/mcp` dans Claude Code.

Dans Réglages, **API et MCP**, la commande complète, clé incluse, peut être copiée juste après la création de la clé.

</Tab>

<Tab value="Cursor">

```json title="~/.cursor/mcp.json"
{
  "mcpServers": {
    "hopla": {
      "url": "https://app.hopla.page/mcp",
      "headers": { "Authorization": "Bearer hopla_…" }
    }
  }
}
```

Le fichier `.cursor/mcp.json` d’un projet est également pris en charge. Hopla apparaît ensuite dans les réglages de Cursor, rubrique MCP.

</Tab>

<Tab value="VS Code">

```json title=".vscode/mcp.json"
{
  "servers": {
    "hopla": {
      "type": "http",
      "url": "https://app.hopla.page/mcp",
      "headers": { "Authorization": "Bearer ${input:hopla-cle}" }
    }
  },
  "inputs": [
    { "id": "hopla-cle", "type": "promptString", "description": "Clé d’API Hopla", "password": true }
  ]
}
```

VS Code demande la clé au premier lancement et la stocke de façon sécurisée : elle n’est pas écrite dans le fichier.

</Tab>

<Tab value="Windsurf">

```json title="~/.codeium/windsurf/mcp_config.json"
{
  "mcpServers": {
    "hopla": {
      "serverUrl": "https://app.hopla.page/mcp",
      "headers": { "Authorization": "Bearer hopla_…" }
    }
  }
}
```

</Tab>

<Tab value="Claude Desktop">

Claude Desktop exécute les serveurs MCP en local : utilisez `mcp-remote` comme passerelle vers Hopla (Node.js requis).

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "hopla": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://app.hopla.page/mcp", "--header", "Authorization:${HOPLA_AUTH}"],
      "env": { "HOPLA_AUTH": "Bearer hopla_…" }
    }
  }
}
```

Le fichier s’ouvre depuis Claude Desktop : Réglages, Développeur, Modifier la configuration. Redémarrez ensuite l’application.

</Tab>

</Tabs>

<Callout title="claude.ai et ChatGPT">
  Les connecteurs personnalisés de claude.ai et de ChatGPT nécessitent une authentification OAuth, non prise en charge pour le moment. Utilisez Claude Code, Cursor, VS Code, Windsurf ou Claude Desktop.
</Callout>

## Outils

25 outils, qui couvrent les opérations de l’API. Avec une clé en lecture seule, seuls les 16 outils de lecture sont exposés.

### Lecture

| Outil | Description |
| --- | --- |
| `lire_page` | La page entière : adresse, offre, réglages et blocs avec leurs id |
| `lire_compte` | L’offre, l’essai, l’abonnement, et ce que l’offre comprend |
| `lire_stats` | Vues, visiteurs et clics d’une période (`jours`, ou `du` et `au`) |
| `lire_semaine` | Les vues des 7 derniers jours et des 7 d’avant |
| `lire_resume` | La période en une phrase, et ses faits marquants |
| `lire_liste` | Le nombre d’inscrits, et où ils partent |
| `lister_inscrits` | Les inscrits, par pages |
| `lire_qr_code` | Le QR code de la page, en image |
| `lire_site` | Le titre, la description, le prix et l’image d’une adresse |
| `lire_flux` | Les derniers articles d’un blog, ou la dernière vidéo d’une chaîne |
| `lire_note_avis` | La note d’une page d’avis, sur 5 |
| `lister_themes` | Les thèmes possibles |
| `lister_reseaux` | Les réseaux qu’une page affiche en icônes |
| `lister_pictos` | Les pictos d’un bloc |
| `lister_types` | Les types de bloc que la page peut poser |
| `lister_cles` | Les clés du compte, sans elles |

### Écriture

| Outil | Description |
| --- | --- |
| `modifier_reglages` | Profil, thème, réseaux, couleurs, référencement… |
| `ajouter_bloc` | Un bloc neuf, en haut ou à une position |
| `modifier_bloc` | Une partie d’un bloc ; `public: false` le masque |
| `dupliquer_bloc` | Une copie, juste sous le bloc d’origine, masquée en option |
| `supprimer_bloc` | Un bloc, pour de bon |
| `ordonner_blocs` | Le nouvel ordre de tous les blocs |
| `envoyer_image` | Une image en data URL, gardée chez Hopla, à poser dans un bloc ou en photo |
| `supprimer_inscrit` | Un inscrit de la liste, pour de bon |
| `envoyer_inscrits` | Les inscrits en attente, vers la newsletter branchée |

## Détails techniques

Le serveur suit la spécification MCP (versions `2025-06-18`, `2025-03-26` et `2024-11-05`). Chaque requête `POST` porte un message JSON-RPC, ou un lot de 50 au plus, et la réponse revient en JSON. Il n’ouvre ni session ni flux : `GET` répond 405.

```bash title="Lister les outils à la main"
curl https://app.hopla.page/mcp \
  -H "Authorization: Bearer $HOPLA_CLE" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "id": 1, "method": "tools/list"}'
```
