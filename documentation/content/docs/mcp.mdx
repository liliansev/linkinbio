title: MCP server

The Hopla MCP server exposes the same operations as the REST API to AI agents: read the page, add links, change the theme, query analytics. The agent selects which tools to call from natural language instructions.

- **Endpoint**: `https://app.hopla.page/mcp`
- **Transport**: Streamable HTTP, JSON responses, stateless
- **Authentication**: `Authorization: Bearer hopla_…`, as for the REST API

## Installation

First create an [API key](/authentication), then configure the server in your client.

<Tabs items={['Claude Code', 'Cursor', 'VS Code', 'Windsurf', 'Claude Desktop']} groupId="client" persist>

<Tab value="Claude Code">

```bash title="Terminal"
claude mcp add --transport http hopla https://app.hopla.page/mcp \
  --header "Authorization: Bearer hopla_…"
```

Add `--scope user` to enable it in all your projects. Then check the connection with `/mcp` in Claude Code.

In Réglages (Settings), **API et MCP**, the full command, key included, can be copied right after the key is created.

</Tab>

<Tab value="Cursor">

```json title="~/.cursor/mcp.json"
{
  "mcpServers": {
    "hopla": {
      "url": "https://app.hopla.page/mcp",
      "headers": { "Authorization": "Bearer hopla_…" }
    }
  }
}
```

A project-level `.cursor/mcp.json` file is also supported. Hopla then appears in Cursor settings, under MCP.

</Tab>

<Tab value="VS Code">

```json title=".vscode/mcp.json"
{
  "servers": {
    "hopla": {
      "type": "http",
      "url": "https://app.hopla.page/mcp",
      "headers": { "Authorization": "Bearer ${input:hopla-api-key}" }
    }
  },
  "inputs": [
    { "id": "hopla-api-key", "type": "promptString", "description": "Hopla API key", "password": true }
  ]
}
```

VS Code prompts for the key on first start and stores it securely: it is not written to the file.

</Tab>

<Tab value="Windsurf">

```json title="~/.codeium/windsurf/mcp_config.json"
{
  "mcpServers": {
    "hopla": {
      "serverUrl": "https://app.hopla.page/mcp",
      "headers": { "Authorization": "Bearer hopla_…" }
    }
  }
}
```

</Tab>

<Tab value="Claude Desktop">

Claude Desktop runs MCP servers locally: use `mcp-remote` as a proxy to Hopla (requires Node.js).

```json title="claude_desktop_config.json"
{
  "mcpServers": {
    "hopla": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://app.hopla.page/mcp", "--header", "Authorization:${HOPLA_AUTH}"],
      "env": { "HOPLA_AUTH": "Bearer hopla_…" }
    }
  }
}
```

Open the file from Claude Desktop: Settings, Developer, Edit Config. Then restart the app.

</Tab>

</Tabs>

<Callout title="claude.ai and ChatGPT">
  Custom connectors in claude.ai and ChatGPT require OAuth, which is not supported yet. Use Claude Code, Cursor, VS Code, Windsurf or Claude Desktop.
</Callout>

## Tools

25 tools, covering the REST API operations. With a read-only key, only the 16 read tools are exposed. Tool names are in French: see the [glossary](/glossary).

### Read tools

| Tool | Description |
| --- | --- |
| `lire_page` | Full page: URL, plan, settings, and blocks with their ids |
| `lire_compte` | Plan, trial, subscription, and included features |
| `lire_stats` | Views, visitors and clicks for a period (`jours`, or `du` and `au`) |
| `lire_semaine` | Views for the last 7 days and the 7 days before |
| `lire_resume` | One-sentence summary of the period and its highlights |
| `lire_liste` | Subscriber count and connected integration |
| `lister_inscrits` | Subscribers, paginated |
| `lire_qr_code` | QR code of the page, as an image |
| `lire_site` | Title, description, price and image of a URL |
| `lire_flux` | Latest posts of a feed, or latest video of a YouTube channel |
| `lire_note_avis` | Rating of a review page, out of 5 |
| `lister_themes` | Available themes |
| `lister_reseaux` | Social networks displayed as icons |
| `lister_pictos` | Block icons |
| `lister_types` | Block types available to the page |
| `lister_cles` | Account API keys, without their secret |

### Write tools

| Tool | Description |
| --- | --- |
| `modifier_reglages` | Update profile, theme, social links, colors, SEO… |
| `ajouter_bloc` | Create a block at the top or at a given position |
| `modifier_bloc` | Partially update a block; `public: false` hides it |
| `dupliquer_bloc` | Duplicate a block right below the original, optionally hidden |
| `supprimer_bloc` | Permanently delete a block |
| `ordonner_blocs` | Reorder all blocks |
| `envoyer_image` | Upload a data URL image, for a block or a profile photo |
| `supprimer_inscrit` | Permanently delete a subscriber |
| `envoyer_inscrits` | Sync pending subscribers to the connected newsletter |

Hopla pages are in French, so prompts usually are too. Agents also understand English instructions.

The agent first calls `lire_page` to get block ids. Changes are visible immediately on the page and in the admin panel.

## Protocol details

The server implements the MCP specification (versions `2025-06-18`, `2025-03-26` and `2024-11-05`). Each `POST` request carries one JSON-RPC message, or a batch of up to 50, and the response is JSON. The server opens no session and no stream: `GET` returns 405.

```bash title="List tools manually"
curl https://app.hopla.page/mcp \
  -H "Authorization: Bearer $HOPLA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc": "2.0", "id": 1, "method": "tools/list"}'
```
