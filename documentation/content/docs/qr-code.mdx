---
title: QR code
description: Générer le QR code d’une page, en SVG ou en PNG.
---

<RoutesDe tag="Partage" />

```bash
curl "https://app.hopla.page/api/v1/qr?format=png&taille=1200" \
  -H "Authorization: Bearer $HOPLA_CLE" -o qr-hopla.png
```

| Paramètre | Valeurs |
| --- | --- |
| `format` | `svg` (par défaut), à agrandir sans perte pour l’impression, ou `png` |
| `taille` | Le côté en pixels, de 120 à 2000 ; 720 par défaut |

Le QR code pointe vers l’URL de partage de la page (le nom de domaine choisi, le cas échéant), suivie de `?s=qr` : les scans sont comptabilisés séparément, sous « QR code », dans les sources des [statistiques](/stats).

Le serveur MCP le renvoie sous forme d’image (`lire_qr_code`).
