title: Quickstart

<Steps>

<Step>

### Create an API key

On [app.hopla.page](https://app.hopla.page/admin), open **Réglages** (Settings), then **API et MCP**, and create a key with write access.

The key starts with `hopla_` and is shown only once: copy it immediately.

</Step>

<Step>

### Store the key in an environment variable

Never hardcode the key in source code: store it in an environment variable.

```bash title="Terminal"
export HOPLA_API_KEY="hopla_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

</Step>

<Step>

### Get the page

<Tabs items={['curl', 'JavaScript', 'Python']} groupId="language" persist>

<Tab value="curl">

```bash
curl https://app.hopla.page/api/v1/page \
  -H "Authorization: Bearer $HOPLA_API_KEY"
```

</Tab>

<Tab value="JavaScript">

```js title="get-page.mjs"
const response = await fetch('https://app.hopla.page/api/v1/page', {
  headers: { Authorization: `Bearer ${process.env.HOPLA_API_KEY}` },
});
const { page, reglages, blocs } = await response.json();
console.log(page.adresse, blocs.length, 'blocks');
```

</Tab>

<Tab value="Python">

```python title="get_page.py"
import os, requests

response = requests.get(
    "https://app.hopla.page/api/v1/page",
    headers={"Authorization": f"Bearer {os.environ['HOPLA_API_KEY']}"},
)
data = response.json()
print(data["page"]["adresse"], len(data["blocs"]), "blocks")
```

</Tab>

</Tabs>

The response contains the page URL (`adresse`), its plan (`offre`), its settings (`reglages`) and its blocks (`blocs`), each with an `id`.

</Step>

<Step>

### Add a link

<Tabs items={['curl', 'JavaScript', 'Python']} groupId="language" persist>

<Tab value="curl">

```bash
curl -X POST https://app.hopla.page/api/v1/blocs \
  -H "Authorization: Bearer $HOPLA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"titre": "Mon nouveau podcast", "url": "https://exemple.fr/podcast"}'
```

</Tab>

<Tab value="JavaScript">

```js title="create-link.mjs"
const response = await fetch('https://app.hopla.page/api/v1/blocs', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.HOPLA_API_KEY}`,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ titre: 'Mon nouveau podcast', url: 'https://exemple.fr/podcast' }),
});
const { bloc } = await response.json();
console.log('Created:', bloc.id);
```

</Tab>

<Tab value="Python">

```python title="create_link.py"
import os, requests

response = requests.post(
    "https://app.hopla.page/api/v1/blocs",
    headers={"Authorization": f"Bearer {os.environ['HOPLA_API_KEY']}"},
    json={"titre": "Mon nouveau podcast", "url": "https://exemple.fr/podcast"},
)
print("Created:", response.json()["bloc"]["id"])
```

</Tab>

</Tabs>

The link is added at the top of the page and is live immediately.

</Step>
