Chaque exemple lit la clé dans la variable d’environnement `HOPLA_CLE` et tient en un seul fichier. Les exemples JavaScript s’exécutent avec Node.js 20 ou supérieur, sans dépendance.

## Ajouter un produit depuis son URL

Reproduit le comportement du back office lorsqu’une URL de fiche produit est collée : lecture du titre, du prix et de la photo, envoi de la photo vers Hopla, création du bloc.

```js title="ajouter-produit.mjs"
const api = 'https://app.hopla.page/api/v1';
const entetes = { Authorization: `Bearer ${process.env.HOPLA_CLE}`, 'Content-Type': 'application/json' };
const appel = async (methode, chemin, corps) => {
  const r = await fetch(api + chemin, { method: methode, headers: entetes, body: JSON.stringify(corps) });
  const json = await r.json();
  if (!r.ok) throw new Error(json.erreur.message);
  return json;
};

const url = process.argv[2]; // node ajouter-produit.mjs https://boutique.exemple.fr/programme
const { apercu } = await appel('POST', '/apercu', { url, image: 'partage' });
const image = apercu.image ? (await appel('POST', '/medias', { image: apercu.image })).media.chemin : '';
const { bloc } = await appel('POST', '/blocs', { type: 'produit', titre: apercu.titre, url, prix: apercu.prix, image });
console.log(`« ${bloc.titre} » ajouté, ${bloc.prix || 'sans prix'}.`);
```

Un bloc `produit` nécessite l’offre Starter ou supérieure.

## Rapport hebdomadaire dans Slack

Publie chaque lundi dans un canal Slack le résumé de la semaine et les trois liens les plus cliqués. Prérequis : l’URL d’un [webhook entrant](https://api.slack.com/messaging/webhooks) Slack dans `SLACK_WEBHOOK`. Une clé en lecture seule suffit.

<Tabs items={['JavaScript', 'Python']} groupId="langage" persist>

<Tab value="JavaScript">

```js title="stats-du-lundi.mjs"
const lire = chemin => fetch(`https://app.hopla.page/api/v1${chemin}`, {
  headers: { Authorization: `Bearer ${process.env.HOPLA_CLE}` },
}).then(r => r.json());

const { resume } = await lire('/stats/resume?periode=7');
const { stats } = await lire('/stats?periode=7');
const top = stats.blocs.toSorted((a, b) => b.clics - a.clics).slice(0, 3).map(b => `• ${b.titre} : ${b.clics} clics`).join('\n');

await fetch(process.env.SLACK_WEBHOOK, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ text: `${resume.phrase}\n${top}` }),
});
```

<Tab value="Python">

```python title="stats_du_lundi.py"
import os, requests

def lire(chemin):
    return requests.get(
        f"https://app.hopla.page/api/v1{chemin}",
        headers={"Authorization": f"Bearer {os.environ['HOPLA_CLE']}"},
    ).json()

phrase = lire("/stats/resume?periode=7")["resume"]["phrase"]
top = "\n".join(f"• {b['titre']} : {b['clics']} clics" for b in sorted(lire("/stats?periode=7")["stats"]["blocs"], key=lambda b: -b["clics"])[:3])
requests.post(os.environ["SLACK_WEBHOOK"], json={"text": f"{phrase}\n{top}"})
```

Planifiez l’exécution chaque lundi à 9 h avec cron (`0 9 * * 1 node stats-du-lundi.mjs`), une GitHub Action planifiée, ou un scénario Make ou n8n.

## Programmer un lancement

Un lien mis en avant, visible du lundi 9 h au dimanche soir, précédé d’un compte à rebours. La programmation nécessite l’offre Starter.

```bash
curl -X POST https://app.hopla.page/api/v1/blocs \
  -H "Authorization: Bearer $HOPLA_CLE" \
  -H "Content-Type: application/json" \
  -d '{
    "titre": "La masterclass est ouverte",
    "url": "https://exemple.fr/masterclass",
    "vedette": true,
    "format": "carte",
    "debut": "2026-11-02T09:00:00+01:00",
    "fin": "2026-11-08T23:59:00+01:00",
    "compteARebours": true
  }'
```

## Mettre à jour un lien récurrent

Un bloc en haut de la page dont l’URL change régulièrement : dernier épisode, dernière vidéo, offre en cours. Son `id` est lu dans `HOPLA_BLOC`.

```js title="lien-de-la-semaine.mjs"
// node lien-de-la-semaine.mjs "Épisode 12 : la reprise" https://exemple.fr/episode-12
const [titre, url] = process.argv.slice(2);
const reponse = await fetch(`https://app.hopla.page/api/v1/blocs/${process.env.HOPLA_BLOC}`, {
  method: 'PATCH',
  headers: { Authorization: `Bearer ${process.env.HOPLA_CLE}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ titre, url, public: true }),
});
console.log(reponse.ok ? 'Lien mis à jour.' : (await reponse.json()).erreur.message);
```

Pour un blog, un podcast ou une chaîne YouTube, les blocs `flux` et `derniere-video` se mettent à jour automatiquement, sans script : voir [Blocs](/blocs).

## Sauvegarde quotidienne des inscrits

Exporte chaque nuit la liste e-mail dans un fichier daté. Une clé en lecture seule suffit.

```bash title="sauvegarde-inscrits.sh"
#!/bin/sh
mkdir -p ~/hopla
curl -sf "https://app.hopla.page/api/v1/inscrits?format=csv" \
  -H "Authorization: Bearer $HOPLA_CLE" \
  -o ~/hopla/inscrits-$(date +%F).csv
```

## Générer un QR code pour l’impression

Le format SVG permet un agrandissement sans perte, quel que soit le format d’impression.

```bash
curl "https://app.hopla.page/api/v1/qr?format=svg" \
  -H "Authorization: Bearer $HOPLA_CLE" -o qr-hopla.svg
```
