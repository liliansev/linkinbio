`GET /page` renvoie la page complète : réglages et blocs. `GET /reglages` renvoie uniquement les réglages.


`PATCH /reglages` modifie uniquement les champs envoyés. Les objets `profil`, `bouton`, `seo`, `couleurs` et `redirection` sont fusionnés champ par champ ; la liste `reseaux` est remplacée entièrement.

```bash
curl -X PATCH https://app.hopla.page/api/v1/reglages \
  -H "Authorization: Bearer $HOPLA_CLE" \
  -H "Content-Type: application/json" \
  -d '{"profil": {"bio": "Coach sportive à Lyon"}, "theme": "onyx"}'
```

La réponse contient l’ensemble des réglages après modification.

## Champs

| Réglage | Valeur |
| --- | --- |
| `profil` | `{ nom, bio, avatar, photo }` : `avatar` est l’adresse https d’une image, `photo` vaut `ronde` ou `grande` |
| `theme` | L’id d’un thème, voir plus bas |
| `reseaux` | `[{ reseau, url }]`, 20 au plus |
| `reseauxPosition` | `haut` (sous la bio) ou `bas` |
| `couleurs` | `{ fond, boutons, accent }` en `#rrggbb` ; vide, celle du thème |
| `bouton` | `{ style, forme, ombre }` : `plein`, `contour`, `doux`, `relief` ou `verre` ; `pilule`, `arrondi` ou `carre` ; `aucune`, `subtile` ou `marquee` |
| `seo` | `{ titre, description }` pour Google et les aperçus de lien |
| `partage` | Le bouton Partager en haut de la page |
| `vouvoiement` | Les mots de la page vouvoient le visiteur |
| `redirection` | `{ url, fin }` envoie toute la page ailleurs jusqu’à `fin` ; `{ "url": "" }` l’arrête |

## Réseaux sociaux

```json
{
  "reseaux": [
    { "reseau": "instagram", "url": "https://instagram.com/camille" },
    { "reseau": "youtube", "url": "https://youtube.com/@camille" },
    { "reseau": "email", "url": "mailto:camille@exemple.fr" }
  ]
}
```
