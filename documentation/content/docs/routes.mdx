URL de base : `https://app.hopla.page/api/v1`, en JSON et en UTF-8. Chaque requête s’authentifie par une [clé d’API](/cles) dans l’en-tête `Authorization`. Les routes dont la méthode n’est pas `GET` modifient la page, sauf les trois routes d’[aperçu d’URL](/lire-le-web) : une clé en lecture seule y reçoit 403 `lecture_seule`.
