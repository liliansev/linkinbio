L’API répond sur `https://app.hopla.page/api/v1`, en JSON et en UTF-8. Chaque appel porte ta [clé](/cles) dans l’en-tête `Authorization`. Une route marquée d’une méthode autre que `GET` modifie ta page, sauf les trois qui [lisent le web](/lire-le-web) : une clé en lecture seule y reçoit 403 `lecture_seule`.
