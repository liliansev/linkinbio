<RoutesDe tag="Statistiques" />

```bash
curl "https://app.hopla.page/api/v1/stats?periode=7" \
  -H "Authorization: Bearer $HOPLA_CLE"
```

## Période

- `periode` : nombre de jours glissants, `7`, `14`, `30` (par défaut), `90` ou `365`.
- `du` et `au` : deux dates au format `AAAA-MM-JJ`, fuseau Europe/Paris. Par exemple `?du=2026-10-01&au=2026-10-15`.

Chaque valeur est accompagnée de celle de la période précédente de même durée, pour le calcul de la tendance.

## Réponse

```json
{
  "stats": {
    "jours": 7,
    "vues": 1284,
    "visiteurs": 902,
    "clics": 311,
    "serie": [{ "jour": "2026-10-22", "vues": 170, "visiteurs": 121, "clics": 40 }],
    "blocs": [{ "id": "a1b2c3d4e5f6", "titre": "Mon nouveau podcast", "clics": 96, "avant": 71 }],
    "sources": [{ "nom": "instagram", "vues": 640, "avant": 512 }],
    "appareils": [{ "nom": "mobile", "vues": 1101 }],
    "pays": [{ "code": "FR", "vues": 1050, "avant": 930 }],
    "precedent": { "vues": 1120, "visiteurs": 801, "clics": 260 }
  }
}
```

| Champ | Description |
| --- | --- |
| `vues`, `visiteurs`, `clics` | Les totaux de la période. Un visiteur compte une fois par jour |
| `serie` | Un jour par entrée, du plus ancien au plus récent |
| `blocs` | Les clics de chaque bloc, et `avant` sur la période d’avant |
| `sources` | D’où viennent les visiteurs : un réseau, un QR code, ou un accès direct |
| `appareils` | Téléphone, ordinateur, tablette |
| `pays` | Le code du pays (`FR`), vide quand on ne le sait pas |
| `precedent` | Les trois totaux de la période d’avant |

## Tendance hebdomadaire (toutes offres)

`GET /stats/semaine` renvoie les vues des 7 derniers jours et des 7 jours précédents, y compris sans historique de statistiques (offre Gratuit).

```json
{ "semaine": { "vues": 412, "avant": 377, "dejaVue": true } }
```

`dejaVue` indique si la page a déjà été vue au moins une fois.

## Résumé

`GET /stats/resume` renvoie le résumé affiché dans « En bref » de l’onglet Stats : une phrase prête à afficher et les faits qui la composent. Il accepte les mêmes paramètres de période que `GET /stats`.

```json
{
  "resume": {
    "phrase": "En 30 jours, 1 284 vues, 12 % de plus que les 30 jours d’avant.",
    "faits": [
      { "texte": "Ta page a eu 1 284 vues, 12 % de plus que les 30 jours d’avant.", "ton": "hausse" },
      { "texte": "« Mon nouveau podcast » a eu 96 clics, 35 % de plus.", "ton": "hausse" }
    ],
    "jours": 30
  }
}
```

`faits` contient une phrase par fait, avec son `ton` : `hausse`, `baisse` ou `neutre`. Voir l’[exemple Slack](/recettes#rapport-hebdomadaire-dans-slack).

## Confidentialité

Les statistiques sont collectées sans cookie, et l’adresse IP des visiteurs n’est jamais stockée.
